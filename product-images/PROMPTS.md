# ZAPAX ENTERPRISE — Product Range Image Prompts

One image per product family. Each image shows every form of that product in labelled bowls. All images share the same white linen towel with a small light-grey "ZAPAX ENTERPRISE" embroidery below the bowls, the same solid indigo stoneware bowls and the same engraved oak name tags, so the catalogue looks like one photo shoot.

**How to use**
1. Copy one prompt and generate it. For text, use **ChatGPT (GPT-image)**, **Gemini**, or **Ideogram**, which spell short words reliably. Midjourney often misspells them.
2. Check every name tag and the towel embroidery. If one is misspelled, ask the same tool: *"Fix only the tag under bowl 3 to read FLAKES. Change nothing else."* or *"Fix only the towel embroidery to read ZAPAX ENTERPRISE. Change nothing else."*
3. Save it as the **file name shown above the prompt** in `product-images/masters/range/`.
4. Run `npm run photos` to make every website size. It also adds the real ZAPAX ENTERPRISE logo as a watermark (small bottom-right + very faint centre).

**Tips**
- Midjourney: add `--ar 3:2 --style raw --stylize 50`.
- Best realism: also upload a phone photo of a real product sample as a reference image.
- Mark AI images as "representative" on the website until real shipment photos replace them.
